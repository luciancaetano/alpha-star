Getting started

Make a small 2D game, run it, then change it. You write TypeScript (JavaScript with checks that catch mistakes); alpha-star opens the window and runs your code. No C++ or AI assistant needed.

Your path: install → play → the one-file tutorial → change your first game → learn the concepts. Keep the API reference for looking things up.

1. Check your tools

You need a code editor, Node.js 20 or newer and a terminal. The prebuilt engine runs on Windows x64 and Linux x64.

node --version
npm --version

Expected: two version numbers, Node v20 or newer. If a command is not found, install Node.js (it includes npm) and reopen the terminal.

2. Create a project

In the folder where you keep projects:

npx @alpha-star/sdk init my-game --template blank
cd my-game
npm install

Accept if npm asks to install the SDK. Expected: a my-game folder with package.json, src, assets and test; npm install downloads the tools and the engine. Run every following command inside my-game.

3. Play it

npm start

Expected: a character in the middle of a dark blue window. Click the window, move with the arrow keys or WASD, press Space to hear a blip and see the character grow for a moment. Close the window (or press Ctrl+C in the terminal) to stop.

4. Check that it works

npm run check
npm test

Expected: check prints nothing (no type errors) and test ends with 3 passed, 0 failed: the starter's tests play the game without a window and check the start position, movement and the Space effect. See Testing.

5. Make your first change

In src/main.ts, change the title line:

title: "My First Game",

Save and run npm start. Expected: the new title in the window's title bar.

Now try hot reload: run npx alpha run --watch, open src/tuning.ts, change speed: 120 to speed: 300 and save. Expected: the game restarts in the same window, and the character is much faster. See Hot reload.

Continue with Your first game for complete, commented code.

Where to edit

FileWhat you change there
src/main.tsTitle, background, controls and assets
src/tuning.tsSpeeds, game size and timings
src/scenes/play.tsWhat happens when play starts (enter) and every step (update)
src/prefabs/player.tsThe data that creates the character
src/types.tsEvery name the game uses: controls, assets, tags, scenes
src/alpha.tsBinds those names to the game and scene builders; leave it as generated
test/main.test.tsAutomated checks of game behavior

If something goes wrong

What you seeWhat to do
node, npm or npx not foundInstall Node.js, then reopen the terminal.
PowerShell says npm.ps1 cannot runUse npm.cmd and npx.cmd, or Command Prompt.
Folder exists and is not emptyPick a new name, such as my-second-game. Existing files are kept.
npm cannot find package.jsonRun cd my-game first.
Engine not foundCheck your OS/architecture and run npm install --include=optional (--omit=optional skips the engine).
TypeScript error with a file and lineFix the first error at that location, save, run npm run check again.
Changes do not appearSave the file and restart npm start; never edit the generated dist/.

On macOS or Linux arm64 the SDK checks and exports code, but there is no prebuilt desktop engine: build one from source and pass --engine <path> or set ALPHA_STAR.
