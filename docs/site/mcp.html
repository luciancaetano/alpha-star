MCP for agents

alpha mcp is a Model Context Protocol server on stdio. An agent uses it to check, test and export the game, then start it and play it: send input, step frame by frame, read the state, take screenshots, read logs, hot-reload.

Claude Code: add .mcp.json to the game folder (or claude mcp add alpha -- npx alpha mcp):

{ "mcpServers": { "alpha": { "command": "npx", "args": ["alpha", "mcp"] } } }
ToolWhat it does
alpha_checkType-check; no problems or file:line:col message lines
alpha_testRun the headless tests; PASS/FAIL per test
alpha_exportBuild the pack (out, standalone)
game_startExport and launch with the control channel (hidden for no window)
game_stateScene, paused, script error, frame, entities (tags, pos, velocity, data...), UI texts
game_stepPause and advance exactly N fixed steps
game_pause / game_resumeStop / restart real-time play
game_inputpress, hold, release an action, or set an axis, per player
game_clickClick a UI element: "document#elementId"
game_screenshotPNG of the current frame
game_logsConsole lines and script errors since a cursor
game_reloadRe-export and hot-reload the running game
game_stopClose the game

A typical loop: edit -> alpha_check -> alpha_test -> game_start -> game_pause -> game_input + game_step -> game_state / game_screenshot -> fix -> game_reload. Input goes through the game's own actions, like a device, and steps are deterministic.

The control channel listens on 127.0.0.1 only and requires a per-launch token. It exists only in dev and release engines; the shipping engine has none of it.
