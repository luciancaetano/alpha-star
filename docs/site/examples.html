Examples

Five small complete games in examples/, each with tests, an AGENTS.md and art generated by a script in its tools/ folder (CC0). They are reference material: short, readable, one way to do each thing. Four of them are also alpha init templates.

ExampleTemplateShows
flappy-Title / play / over / settings scenes, RmlUi with buttons and gamepad navigation, streamed OGG music, bus volumes, English / Portuguese, best score save, TTF pixel font
platformerplatformerSprite sheets and animation, a Tiled map with merged colliders, camera follow / bounds / shake, raycast ground check, one-way ledge, tweened lift, parallax layer, dust particles, world text
topdowntopdownTwo players (ctx.input.player(n)), movement axes, auto-aim, sensor bullets, queryCircle bomb, one-shot particle blasts, rumble, panned sounds, best score save
puzzlepuzzleSokoban rules as pure functions tested directly, undo, level progress and best moves in saves, i18n with plural forms and data-t, reduced motion, high contrast
shmupshmupCollision categories, kinematic enemies, fast sensor shots, 120 stars moved with the ctx.positions batch API, parallax and fx layers, generated WAV music with fade in / out, blink tween

Run one:

cd examples/shmup
npm install
npm test
npm start
