interface GameTypes

Every name a game uses. Misspelling any of them is a compile error.

export interface GameTypes
actions: string;Input actions, e.g. "jump" | "fire".
axes?: string;Analog axes (config.axes), e.g. "moveX" | "moveY". Optional: omit if the game has none.
sounds: string;Sound asset names.
images: string;Image asset names (use never if the game has none).
tags: string;Entity tags used by find / collisions.
scenes: { [name: string]: SceneParams };Scene name -> params its enter() receives (undefined = none).
ui: UiTypes;UI document name (assets.ui) -> ids of its elements that scripts touch, e.g. { hud: "score"; over: "score" | "again" }. Use {} if the game has no UI, never for a document scripts only show/hide.
sheets?: { [sheet: string]: string };Sprite sheet name (assets.sheets) -> its animation names, e.g. { hero: "idle" | "run" | "jump" }. Optional: omit if the game has none.
maps?: string;Tiled map names (assets.maps), e.g. "level1". Optional.
layers?: string;Draw layer names (config.layers), e.g. "bg" | "fx". Optional.
fonts?: string;Font names (assets.fonts), used by world text and .rcss. Optional (any name).
categories?: string;Collision category names (config.collision.categories), e.g. "player" | "enemy". Optional.
music?: string;Streamed music names (assets.music), e.g. "theme" | "boss". Optional.
locales?: string;Locale names (assets.locales), e.g. "en" | "pt". Optional.
buses?: string;Extra volume buses (config.audio.buses), e.g. "ambience". Optional.
shaders?: { [shader: string]: string };Custom shader names (assets.shaders) -> their uniform names, e.g. { wave: "amount" | "time" } (never for a shader without uniforms). Optional.

interface TextShape

World text: drawn in the world (moves with the camera, z ordered like any shape). With font (an assets.fonts name) it is drawn size pixels high; without, the built-in 8x8 font at the nearest whole multiple of 8. Glyphs are rasterized at the screen's resolution (window scale x camera zoom), so text stays sharp. pos is the anchor: align (default "center") picks which end of the lines sits on it; the block of lines is vertically centered. Any Unicode text: TrueType/OpenType fonts are shaped (ligatures, Arabic joining, Devanagari/Thai clusters), mixed right-to-left and left-to-right runs are ordered by the Unicode bidi algorithm, characters the font lacks come from its fallbacks (FontAsset), and what no font has draws as a box (with a warning in the log). "\n" starts a new line. Invalid Unicode (an unpaired surrogate from slicing an emoji) is an error naming where it is.

export interface TextShape<F extends string = never>
text: string;
font?: F;
size?: number;Pixels (1..256), default 16.
color?: Color;Default "#ffffff".
align?: "left" | "center" | "right";
dir?: "auto" | "ltr" | "rtl";Paragraph direction: "auto" (default) takes it from the first strong letter (Arabic/Hebrew = right to left), "ltr" / "rtl" force it.
width?: number;Wrap lines at this many pixels (0 = default: only at "\n"). Lines break after spaces and between CJK characters (not before closing punctuation such as 。、）).

interface EmitterSpec

A particle emitter on the entity. Particles are born at the entity (it may move: they follow it as they are born) and then fly on their own in world space. Simulated on the fixed step with the game's seeded random (deterministic), at most 20000 live particles in the whole scene. A one-shot emitter emits its burst once and its entity is destroyed when the last particle dies.

export interface EmitterSpec<I extends string = never, S extends string = never> extends Look
rate?: number;Particles per second (default 0: only bursts).
burst?: number;Particles on the first step (default 0). entity.emit(n) bursts later.
lifetime?: Span;Seconds each particle lives (default 1).
speed?: Span;Pixels per second (default 0).
angle?: Span;Degrees: 0 = right, 90 = down, 270 = up (default [0, 360]: every way).
gravity?: Vec2;Pixels per second squared, e.g. [0, 300].
size?: Span;Pixel size at birth and at death (default 4).
color?: Color | [Color, Color];One color, or [birth, death] (default ["#ffffffff", "#ffffff00"]: fades out).
shape?: "circle" | "rect" | { image: I } | { sheet: S; frame?: number };Particle shape (default "circle"); images and sheet frames are tinted by color.
smooth?: boolean;Circle/rect particles: true = antialiased (1 px feathered) edges, false = crisp. Default: !config.pixelMode, like filled shapes. Image/sheet particles follow their image's filter.
max?: number;Most live particles of this emitter, 1..20000 (default 100).
oneShot?: boolean;

interface ShaderAsset

A custom full-screen shader: a Vulkan GLSL fragment shader (.frag; see the shaders guide for its contract) and its float uniforms with defaults, in the order of its std140 uniform block (layout(set = 3, binding = 0), floats only), at most 16. alpha run compiles it to SPIR-V (glslang) and MSL (shadercross) on load (and on every save); alpha export puts the compiled .spv and .msl in the pack instead of the .frag. Runs on Vulkan today (Windows, Linux, Android; the .msl is for Metal, macOS/iOS not yet), which games with shaders ask for; elsewhere the effect is skipped with a logged warning.

export interface ShaderAsset<U extends string>
file: string;
uniforms?: Record<U, number>;

interface PostFx

The current scene's post effects, drawn over the (lit) world in the order first added; UI and dev tools stay unaffected. Each scene starts with none. Render-only: simulate() and game state never see them. Built-ins work on every renderer (software too); custom shaders (assets.shaders, same calls) need the GPU renderer.

export interface PostFx<S = {}>
add<N extends EffectOf<S>>(name: N, params?: EffectParams<S, N>): void;Adds the effect, or replaces its params when already added (keeping its place).
set<N extends EffectOf<S>>(name: N, params?: EffectParams<S, N>): void;Like add, for an effect already added (error otherwise). Missing params reset to defaults.
remove(name: EffectOf<S>): boolean;False when it was not added.
clear(): void;
list(): EffectOf<S>[];Names in draw order.

interface WindowConfig

config.window. The game is designed at config.size and scaled to the screen keeping its aspect (like Godot's stretch aspect). aspect: "expand" (default; fills the screen by showing more world on the longer axis, never bars), "keep_width" (width fixed: taller screens show more height, wider ones get side bars; portrait games), "keep_height" (height fixed: wider screens show more width, taller ones get bars; landscape games), "keep" (exactly config.size, letterbox bars). scale: "fractional" (default) or "integer" (whole multiples only: crisp pixel art; the revealed axes still fill the screen). The revealed world is ctx.camera.view; screen-space HUD uses ctx.safeArea, and UI elements with class="safe" are padded by it. (scaling was replaced: letterbox -> aspect "keep", integer -> scale "integer".)

export interface WindowConfig
fullscreen?: boolean;
aspect?: "expand" | "keep_width" | "keep_height" | "keep";
scale?: "fractional" | "integer";
resizable?: boolean;Default true.
altEnter?: boolean;Alt+Enter toggles fullscreen (default true).
borderless?: boolean;No title bar or frame (default false).
alwaysOnTop?: boolean;Stays above other windows (default false).
maximized?: boolean;Starts maximized (default false).
vsync?: boolean;Wait for the display refresh (default true); false draws as fast as possible (more CPU/GPU).

Persistent key/value storage; survives restarts. Each slot is one file in the player's data folder, written atomically (temp file + rename, the previous one kept as .bak; a damaged file falls back to its .bak with a logged warning) and stamped with config.save.version (older files go through config.save.migrate).

type ImageFilter

How an image is sampled when drawn scaled or rotated:

  • "nearest": crisp pixel art; at non-whole scales or rotated, pixels come out uneven/jagged.
  • "linear": smooth (photos, painted art); pixel art gets blurry.
  • "sharp": pixel art at any size or angle: square pixels with soft ~1 screen-pixel edges (the texture is grown 4x with nearest, then drawn linear; 16x the texture memory).

Default: config.pixelMode (true = "nearest", false = "linear").

export type ImageFilter = "nearest" | "linear" | "sharp";

type ImageAsset

An image (or a map's tilesets): "path", or { file, filter }.

export type ImageAsset = string | { file: string; filter?: ImageFilter };

type FontAsset

A font: "path" or { file, pixelMode, license, fallbacks }; license is its license file, credited in the pack. Text is rasterized at the screen's real resolution, so it stays sharp at any window scale; bitmap fonts draw at whole multiples of their size. pixelMode true: TrueType glyphs are rendered monochrome (pixel fonts stay crisp). fallbacks (TrueType/OpenType only): other assets.fonts names, tried in order for characters this font lacks, e.g. main: { file: "NotoSans.ttf", fallbacks: ["arabic", "cjk"] }.

export type FontAsset<F extends string = string> =
    | string
    | { file: string; pixelMode?: boolean; license?: string; fallbacks?: F[] };

function simulate

Headless, deterministic: same game + options => same run. Every call is a fresh game instance (new world and timers, random seeded from config.seed, in-memory ctx.save and settings, empty unless opts.saves / opts.settings seed them), with no window and no audio output (music and buses are still tracked). A script error stops the run; expect.noErrors() reports it. Tests are the exported functions of test/main.test.ts, run by alpha test.
