# Glossary

| Term | Meaning |
|---|---|
| Agent | An AI model that writes game scripts through the script API and MCP. |
| Vibecoder | End user who describes a game in natural language; never writes code. |
| Core | Dependency-free C++ domain code in `src/core`; pure, fast to test. |
| Entity | ECS identifier (EnTT) for a game object; scripts see an opaque handle. |
| Script API | The QuickJS-ng surface agents program against. The product. |
| Gate | `tools/gate.py`: build + tests + limits + CRAP + duplication. |
| World | One scene's entities (`ecs::World`): spawn, deferred destroy, find by tag in creation order, transform/velocity, `step(dt)` → hit/enter events, draw list. |
| EntityId | Opaque `uint32` handle (EnTT id + version); a stale handle is detected as dead, never reused silently. |
| Tag | Interned name (`TagRegistry`, max 64); entities carry a `TagSet` bitset. |
| Action | Named input (`Actions`) bound to device input names (`input_names()`); has pressed/down/released per fixed step. |
| Fixed step | Simulation always advances 1/60 s (`FixedStep`); real time only decides how many steps run. |
| Hit / Enter | Physics events: solid contact began / overlap with a sensor began (`a` = visitor, `b` = sensor). |
| Frame | Everything drawn in one frame (`render::Frame`): background, ordered shapes, and the engine's own error overlay lines (debug font; never a game API). |
| Host | `script::Host`: loads one compiled game module, boots it, steps it, builds frames. Any JS error pauses the game and is shown on screen. |
| Runtime | `src/script/runtime.js`, embedded in the binary: scenes, `ctx`, entity proxies, timers, collision dispatch. Talks to C++ only via `__native`. |
| Native | C++ function exposed to the runtime on `__native`; validates every argument and throws errors that name the field. |
| Asset | File or synth spec declared in `game.assets`; every asset is loaded at boot (preload) before the start scene. Paths are relative to the game `.js`. |
| Synth | Procedural sound spec: a note `{ wave, freq, duration, volume?, attack?, release? }` or a list of notes. Same spec → same samples (`core::synthesize`). |
| Mixer | `core::Mixer`: voices with volume/pitch/loop over shared sample buffers; main thread only, drained into the device each frame (`platform::AudioOut`). |
| Voice | One playing sound, returned by `ctx.audio.play` / `tone`; `stop()`, `playing`. |
| Sprite | Shape `{ image, size? }`: an image asset drawn as a rotated texture in z order. |
| Call budget | `kCallBudget` (250 ms, `script/js_engine.hpp`): wall time one script call (import, enter, update, handler) may run; past it QuickJS is interrupted and the game pauses with "script ran longer than 250 ms ... (infinite loop?)". |
| Memory limit | `kMemoryLimitMb` (256 MB): QuickJS heap cap; hitting it pauses with "script ran out of memory (limit 256 MB)". |
| Save path | `SavePathFor(title)`: where `ctx.save` persists; the engine uses `SDL_GetPrefPath("alpha-star", title)/save.json` (per-user data dir), tests pass a temp file. |
| Game instance | One running game inside the JS context: runtime state in a `createInstance(id, save)` closure (`runtime.js`) + native `ScriptState` under the same id in `Instances` (`script/instances.hpp`). The engine's game is instance 0; each `simulate()` is a fresh one, destroyed when the run ends. Natives act on the *active* instance; the runtime selects it around every call. |
| simulate | `alpha/test`: runs a game headlessly in a fresh instance for `round(seconds*60)` fixed 1/60 steps, pressing actions (per player: `inputs` may be an array), holding axis values (`axes: { name: [[frame, value]] }`, held until the next entry) and clicking UI elements (`clicks: { "doc#id": [frames] }`) on given 0-based frames; in-memory save, no window, no audio. Returns `Run { frames, expect }` from a snapshot (scene, tag counts, UI texts/visibility, error). |
| Test mode | `alpha_star --test <tests.js>`: imports a bundled test module, calls each exported function once (name order), prints `PASS`/`FAIL` lines, exit 0 iff all pass. `alpha test` bundles `test/main.test.ts` to `build/test/main.test.js` and runs it. |
| Source map | esbuild's inline v3 map at the end of a bundle; `core::SourceMap` (pure VLQ decoder) + `script::load_bundle_map`; `Host` rewrites `<bundle>:LINE:COL` in errors to `src/...ts:LINE:COL` (overlay, stderr, test failures). Sources are relative to the bundle's final location. |
| Dev tools | Built-in engine tools on Dear ImGui (`src/devtools/`), toggled with F12 or gamepad Back+Start, drawn over the game frame before present: overlay, entity inspector, script console, time controls, physics view. Only in `ALPHA_DEVTOOLS` builds (dev and release presets: `alpha run`, `npm start`, `--watch`); shipping engines contain none of it. Never visible to scripts. Game UI is a separate system. |
| DevSnapshot | `devtools::snapshot(host, FrameStats)`: plain data the overlay shows (fps, frame ms, fixed steps this frame, last step's script call ms vs the 250 ms budget, entities, mixer voices, scene, error). |
| Log ring | `core::LogRing`: newest N (200) `console.log/warn/error` lines and pausing script errors, shared by every game instance (`Instances::log`); the dev tools console reads it. console.* also prints `[log|warn|error] text` to stderr. |
| Control channel | `alpha-control` protocol (`src/mcp/`, `ALPHA_MCP`: dev + release, never shipping): `alpha_star <pack> --control PORT [--hidden]` listens on 127.0.0.1 only, one client, non-blocking sockets polled on the main thread after each frame is drawn (before present). Line-delimited flat JSON: `{"id", "cmd", ...}` -> `{"id", "ok", ...}` or `{"ok": false, "error"}`; greeting first; with `$ALPHA_CONTROL_TOKEN` set, `hello {token}` must come first. Commands: hello state pause resume step press hold release axis click screenshot logs quit. |
| Agent input | `mcp::AgentInput`: actions the agent pressed (one step) or holds, OR-ed into each step's device `InputFrame` through the action's bound inputs, so the game sees a device; axes via `core::Axes::hold` (held across updates until released). |
| Agent pause | The control channel's pause: the clock runs no steps; `step N` runs N fixed steps synchronously; independent of the dev tools' and the script-error pause. |
| alpha mcp | The SDK's MCP server (stdio, `@modelcontextprotocol/sdk`): tools `alpha_check/export/test` and `game_start/state/step/pause/resume/input/click/screenshot/logs/stop` over the control channel of a release engine it launches with a random token. |
| Time control | `devtools::TimeControl`: dev-tools pause over the fixed-step clock; paused runs 0 steps except exactly one after each Step request. Independent of a script-error pause. |
| Physics view | Dev tools toggle: each body's collider (`World::colliders`, from the `Collider` component) drawn as an unfilled outline over the game (green solid, yellow sensor). |
| Game UI | RmlUi (`src/ui/`): HTML/CSS-like `.rml` documents + `.rcss` styles, declared in `assets.ui`, fonts in `assets.fonts` (name = `font-family`). One `ui::Ui` (Rml::Context, game logical size) per game instance; documents load hidden at boot, reload hidden on every scene change. Script API `ctx.ui.show/hide/set/on`. No default stylesheet: `div`/`p` are inline unless the RCSS says `display: block`. |
| UI handler | Function registered with `ctx.ui.on(doc, id, "click" \| "back", fn)`; events queue the handler id and the runtime runs queued handlers at the start of the next step (deterministic, never re-entrant). |
| Input consumption | `ui::consumes`: an input the game UI acted on (click on an element with a handler or a form control, focus move, Enter/Space/A on a focused element, Escape/B with a "back" handler, typing in a text field) never also reaches game actions. Order: dev tools, then game UI, then game input. |
| PadNav | `ui::PadNav`: gamepad focus navigation from the D-pad and left stick (deadzone 0.5, first move at once, repeat after 400 ms then every 120 ms). |
| Build flavor | A set of `ALPHA_*` compile flags (`cmake/Flavors.cmake`), always defined 0/1 and tested with `#if`. Presets: **dev** (everything ON, tests), **release** (`ALPHA_DEBUG_TOOLS` + `ALPHA_MCP`: what `alpha run`/`alpha test`/`alpha mcp` use), **shipping** (`ALPHA_SHIPPING`: what players get). |
| Shipping engine | `ALPHA_SHIPPING` build: no dev tools, MCP, debug CLI flags, test runner or `alpha/test` (importing it lists the built-in modules that exist); IPO/LTO, stripped, no console window; every CLI flag ignored; logs (console.*, script errors, SDL_Log) go to `<pref dir>/log.txt`. Staged at `alpha-sdk/engine/<target>/shipping/`, copied by `alpha export --standalone`, verified by `tools/check_shipping.py`. |
| Pref dir | Per-user data dir `SDL_GetPrefPath("alpha-star", <config.title>)` (`platform::pref_file`): `save.json` and, in shipping, `log.txt`. |
| Player | 1..4 (`core::kMaxPlayers`; 0-based inside the engine). Player 1 owns keyboard, mouse and the first gamepad slot. `ctx.input.pressed/down/released/axis` = any player; `ctx.input.player(n)` = one; `ctx.input.players()` = 1 up to the highest connected gamepad's player. |
| Pad slot | `core::PadSlots`: player slot per gamepad in connection order. A disconnected slot stays reserved for that device kind (GUID) and goes back to it on reconnect; new devices take a never-used slot first, then any free one; a fifth pad is ignored. `platform::Gamepads` opens/closes SDL gamepads into slots. |
| Analog | Raw gamepad axis (`core::Analog`): `GamepadLeftX/LeftY/RightX/RightY` in [-1, 1] (+y down), `GamepadLT/RT` in [0, 1]. Its digital view (`analog_buttons`, past 0.5) is bindable in actions: `GamepadLeftX-`/`+`, `GamepadLeftY-` (= up), ..., `GamepadLT`, `GamepadRT`. |
| Axis | Named analog control in `config.axes` (`core::Axes`): sources are analog names or `"Neg/Pos"` input pairs (`"A/D"`, reading -1/0/1); the axis reads the strongest source, clamped to [-1, 1]. |
| Deadzone | `config.deadzone` (default 0.2, 0 <= d < 1): radial on each stick (vector length rescaled, direction kept), axial on triggers; values past it rescale to reach 1. Applies to axes, not to the digital view (threshold 0.5) nor to the UI's PadNav (0.5). |
| Input frame | `core::InputFrame`: what every player held (`InputSet`) plus raw analog values during one fixed step, and the connected player count; produced by `platform::consume`, fed to `core::Controls` (actions + axes + players + rumble requests). |
| Rumble | `ctx.input.rumble(strength 0..1, seconds 0..10, player?)` (all players if omitted): validated, queued per player (latest wins) in `core::Controls`, taken by the main loop each frame and started with `SDL_RumbleGamepad`; no-op without a pad and in simulate. |
| Unmapped joystick | A joystick SDL's built-in gamepad database (plus `SDL_GAMECONTROLLERCONFIG`) cannot map: reported once per GUID in the log (debug-tools builds), never a player. |
| Hot reload | `script::Host::reload` (dev/release: `ALPHA_DEBUG_TOOLS`): boots the game again from its main.js in a fresh `script::Vm` (new QuickJS engine, every asset reread) and swaps it in only if it booted; otherwise the old game keeps running and the error shows as an overlay (`reload_error`), in the log and in the control reply. Carried over: the save, the scene + params (JSON-safe), `ctx.state` per the JSON rule. Triggers: control command `reload` (MCP `game_reload`) and the pack watch. |
| Vm | `script::Vm`: one QuickJS engine + its game instances + the imported bundle and source map. `Host` owns one; the log ring lives in the Host so lines survive a reload. |
| JSON-safe | A value equal to itself after `JSON.stringify`/`JSON.parse`: null, booleans, finite numbers, strings, arrays and plain objects of those. Only JSON-safe `ctx.state` and scene params survive a hot reload. |
| Pack watch | `core::PackWatch` (dev/release): main-loop poll of every file under the pack (size + mtime, ~4 scans/s); says "reload" once the pack has been quiet 0.3 s after a change. Off with `--frames` and under `--control`. `alpha run --watch` is the SDK side (re-export on source change, debounced 200 ms). |
| Camera | `core::Camera` (one per scene world, `ctx.camera`): `pos` = world point at the screen center, `zoom`, `rotation`, optional follow (entity, `lerp` per fixed step, `deadzone`), `bounds` box and a shake (intensity fading over seconds, xorshift noise seeded per camera: deterministic). Stepped in `World::step` after physics; the identity camera (pos = size/2, zoom 1) maps world pixels to screen pixels. |
| View | `core::View`: what the renderer needs from the camera (center incl. shake, zoom, rotation, screen size). `World::view(blend)` interpolates previous -> current like transforms. Shapes go through it; texts, the game UI and dev tools do not. |
| Culling | The renderer skips every item whose world AABB (`render::bounds_of`) misses `visible_area(view)`, and every tile cell outside it. `RenderStats` (drawn / culled / draw calls) of the last frame; logged after `--frames` runs in dev/release. |
| Batch | A run of consecutive (z-ordered) items sharing one texture (or none, for plain shapes), sent as one `SDL_RenderGeometry` call. |
| Picture | `core::Picture`: what a game calls an image: a decoded image plus the region of it to use (the whole file, or its place in an atlas page). |
| Sprite sheet | `core::Sheet` (`assets.sheets`): a grid of equal frames in a picture (row-major, frame 0 top-left) + named animations (`frames`, `fps` default 10, `loop` default true). Shape `{ sheet, animation? }`; `ecs::Animator` advances it on the fixed step into the shape's `src`. |
| Atlas | `alpha export` packs every decodable 8-bit PNG of `assets.images` and sheet images into `alpha-atlas-N.png` pages (shelf packing, 2 px gaps, max 2048) + `alpha-atlas.json` (file -> [page, [x, y, w, h]]); the runtime loads pictures through it, so game code never sees it. `--no-atlas` opts out; tilesets are not packed. |
| Tile layer | One entity per Tiled tile layer and tileset (`core::TileGrid`): cells with their tileset source rects, drawn as one batch, culled per cell. |
| Map | A Tiled map (`assets.maps`, `.tmj` JSON, tilesets embedded or `.tsj`, CSV layer data), parsed once at boot by the embedded module `alpha:maps`. `ctx.spawnMap(name, { collide, z, pos })` draws tile layers and turns `collide` layers into static boxes (`core::merge_cells`: runs, then equal spans stacked) tagged with the layer name; `ctx.map(name).objects(layer)` = object layer as plain data. |
| Emitter | `core::EmitterSpec` (spawn spec `emitter`) + `core::Emitter` (ECS `Emission`): particles born at the entity each fixed step (`rate` with carried fractions, `burst` on the first step, `entity.emit(n)`), then flying alone in world space; per-emitter pool reserved at `max`, whole world capped at `core::kMaxParticles` (20000). Random picks use the game's seeded stream. One-shot: burst only, entity destroyed after the last particle. |
| Particle | `core::Particle` (pos, prev, vel, age, life); drawn as `core::ParticleQuad`s on one `DrawItem` per emitter, one batch, culled per particle. Size and color go start -> end over the lifetime. |
| Look | The tint (color multiply incl. alpha), alpha (0..1) and blend (`alpha`, `add`, `multiply`) every `ShapeSpec` carries; for an emitter-only entity, its particle look. Batches break on blend. |
| Layer | `core::Layer` from `config.layers` (name, z, parallax); `layer:` on a spec. Draw order is layer z, then entity z, then creation. Parallax scales the camera's offset/zoom/rotation for that layer (`core::parallax_view`): 0 = fixed to the screen, 1 = the world. |
| World text | Shape `{ text, font?, size, color, align, dir, width }` (valid UTF-8, any script): the script layer resolves the font (`TextLook::face`, a `core::FontSource`; no font = the built-in 8x8) and the box at 1:1; the renderer shapes it every frame at the output density (window scale x camera zoom; shapes are cached per source) and tracks each font size's current atlas image (`render::FontCache` frees replaced textures), the lines starting on a whole output pixel. |
| Output grid | `core::PixelGrid`: how logical (game) pixels land on output (window) pixels, `output = logical * scale + offset`, read from SDL's logical presentation rect (high-DPI included, `SDL_WINDOW_HIGH_PIXEL_DENSITY`). `snap` moves a point onto a whole output pixel. Text is made at this resolution so the presentation never resamples it. |
| Font source | `core::FontSource` (`platform/fonts`): an `assets.fonts` file loaded once; `shape(TextRequest)` gives `core::ShapedText` (lines of `PlacedGlyph` in visual order + the atlas holding them), laid out by `core::layout_text`. TrueType/OpenType (`platform/truetype`): a chain = the font + its `fallbacks`, HarfBuzz shaping per run item (`platform/run_items`: one font and script each), hinted FreeType glyphs (`platform/glyphs`, `pixelMode` true = monochrome) in a `platform::GlyphAtlas` per pixel size; BMFont (`.fnt` text or XML + PNG pages, `core::parse_bmfont`): one atlas at its native size, one glyph per code point, kerning pairs. `core::font_scale` picks the size: scalable = size x density (max 320 px), bitmap = native at the nearest whole multiple. |
| Text pipeline | `platform/text_shaper`: UTF-8 (`core/utf8`, checked at the script boundary by `script::text_arg`) -> paragraphs at "\n" -> bidi (`platform::BidiParagraph`, SheenBidi, `core::TextDir` auto/ltr/rtl) -> per-code-point advances -> lines (`core::wrap_lines`: spaces, between CJK, not before closing punctuation) -> each line's runs shaped by the source (`platform::RunShaper`) in visual order on whole pixels. |
| Fallback / tofu | A TrueType font's `fallbacks` (other assets.fonts names) draw the code points it lacks; glyph keys carry the chain index (`core::glyph_key(font, id)`). What no font has is `core::kTofuKey`, a box, warned once per font and Unicode block (`platform::MissingGlyphs`). |
| Glyph atlas | `platform::GlyphAtlas`: one font chain at one pixel size, glyphs rasterized on demand into a growing RGBA image (at most `core::kMaxGlyphAtlasSide` square, `kGlyphAtlasSizes` sizes kept per font); full = start over with the glyphs the current text needs. Every change publishes a new immutable `core::FontAtlas`. |
| Built-in font | The public domain 8x8 VGA glyphs (Marcel Sondaar / IBM, as shipped in SDL3's debug text), generated into `platform/default_font_data` by `tools/make_default_font.py`: world text without `font`, and every UI family when a game loads no font. |
| UI font engine | `ui::FontEngine` (an `Rml::FontEngineInterface`; RmlUi is built with no font engine of its own): every family is a font source drawn by `ui::TextFace` at size x density with the same shaping as world text; RCSS `direction` is the paragraph direction; a new atlas image bumps the face version so RmlUi regenerates its text. On a density change (resize, DPI) `Rml::ReleaseFontResources` remakes every face. `RmlRenderer` moves geometry onto whole output pixels and draws generated (glyph) textures with nearest filtering. |
| Third-party notices | `THIRD_PARTY_NOTICES.txt`, written by `alpha export` into every pack: `alpha-sdk/notices/*.txt` (made by `tools/make_notices.py` from the fetched dependencies' license files: FreeType FTL credit, SDL3, SDL_image + stb_image, Box2D, EnTT, QuickJS-ng, RmlUi, HarfBuzz, SheenBidi, stb_vorbis, dr_mp3, the built-in font, alpha-star) plus each `assets.fonts.<name>.license` file. Dear ImGui never ships, so it is not listed. |
| Scaling | `config.window.scaling` (`core::Scaling`): letterbox (default), integer (whole multiples, pixel art), stretch, expand (logical size grows to the window's aspect; camera and UI see more), crop (fills keeping the aspect, edges cut). Window flags: `fullscreen`, `resizable`, `altEnter`, `borderless`, `alwaysOnTop`, `maximized`, `vsync` (`core::WindowConfig`). Input is mapped to game pixels by SDL's logical presentation in every mode. Phones always open fullscreen (`core::starts_fullscreen`: immersive, into the cutout). |
| Safe area | `ctx.safeArea`: `[x, y, w, h]` in screen (game) pixels that no display cutout, rounded corner or system bar hides; `core::safe_insets` turns `SDL_GetWindowSafeArea` into `core::Insets` (left/top/right/bottom) through the logical presentation, kept in `core::WindowState::safe` every frame. The whole view on desktop and headless. |
| Contact | What a hit handler gets third: `normal` (unit, first entity -> second), `point`, `speed` (approach speed along the normal, px/s, from Box2D hit events; 0 when sliding into contact). Hit ends / sensor exits are pairs only, reported while both entities live. |
| Collision category | A `config.collision.categories` name (max 63); bit i + 1 (bit 0 = no category). Body `category` / `collidesWith` become a Box2D filter; queries filter with `categories`. |
| One-way collider | `collider.oneWay`: solid only for bodies coming from above (smaller y). Box2D pre-solve disables the contact unless the normal from the collider to the other body points up. |
| Ray / area query | `ctx.raycast` (first solid hit, sensors skipped), `raycastAll` (nearest first), `queryCircle` / `queryRect` (overlaps incl. sensors, oldest first); filter by `tags` and `categories`. `physics/queries`. |
| Joint | `ctx.joint({ type: revolute \| distance \| rope \| weld \| prismatic, a, b, ... })` -> handle (`alive`, `destroy()`); `physics::Joints` keeps handles (never reused); a joint dies with either body. |
| Tween | `ctx.tween(target, { to, seconds, ease, delay, yoyo, repeat, onDone })`: eased numbers on the fixed step (`alpha:tween`), scene-scoped. Kinematic bodies tweened on x/y move by velocity (and stop the step after), so riders are carried. |
| Parent / child | `spawn({ parent })`: `ecs::Parent` link (local offset + rotation); children follow on set and every step (oldest first), die with the parent; `entity.parent` / `entity.children`. |
| Entity data | `entity.data`: a JSON-safe plain object per entity kept by the runtime and mirrored to `ecs::Data` (JSON text) after each step for MCP state / tools. |
| Scale | `entity.scale`: multiplier of the spawned shape geometry (and text size), `ecs::Scaled`. |
| pixelMode | Look: `true` = nearest filtering + hard shape edges (crisp pixel art, default), `false` = linear filtering + antialiased circle/rect edges (smooth). `config.pixelMode` default; images/sheets/maps override with `filter`, fonts with `{ file, pixelMode }`, filled shapes with `smooth` (`core::ShapeSpec::smooth`). |
| Image filter | `core::Filter` on `core::Image`: `"nearest"` (crisp), `"linear"` (smooth), `"sharp"` (sharp bilinear: the renderer uploads the image grown `core::sharp_factor` (<= 4) times with nearest, sampled linear: square texels with soft edges at any scale/rotation; `core/image_filter`). `alpha export` packs each filter on its own atlas pages (`alpha-atlas.json` `filters.<filter>`; sharp pages <= 1024 px). |
| Smooth shape | A filled circle/rect (and its outline) with `ShapeSpec::smooth`: `render::tessellate` fans to the edge pulled in half an output pixel, then a ring to half a pixel out whose outer vertices have alpha 0 (ImGui-style feather, no shaders). The pixel size in world units is 1 / (camera zoom x layer parallax zoom x window scale). Circle segments follow the on-screen radius (`circle_segments`, max error 0.3 px, 12..128) for crisp and smooth shapes. |
| Bus | A named volume (`core::Mixer` buses): `master` (scales everything), `music`, `sfx` (default for sounds and tones), `voice`, plus `config.audio.buses`. A sound declares its bus (`{ file, bus }` / `{ synth, bus }`); `ctx.audio.bus(name).volume` sets it and persists it in settings. |
| Music (stream) | `assets.music` file played by `ctx.audio.music` / `crossfade`: a `core::Stream` (`platform/music_stream`) decoding the compressed bytes (held in memory, no file kept open) a chunk at a time inside `Mixer::mix` on the main thread, converted to 48 kHz stereo. One `core::MusicTrack` plays; a crossfade keeps the fading one until it reaches 0. |
| Pan | `PlayOptions.pan` -1..1: balance of a mono sound in the stereo mix (0 = both sides at full volume). |
| Save slot | One JSON file `{ version, data }` in the player's data folder: `ctx.save` = slot `main` (`save.json`), `ctx.save.slot(name)` = `save-<name>.json`. Written atomically with a `.bak`; read once, migrated by `config.save.migrate(data, fromVersion)` when older (files without a version are version 1). Test runs keep slots in memory (`memoryStore`). |
| Settings | The player's preferences, `settings.json` apart from saves: bus volumes, locale, fullscreen, rebinds, uiScale, highContrast, reducedMotion. Applied at boot leniently (unusable values skipped with a warning); changed where they live (`audio.bus`, `ctx.locale`, `window.fullscreen`, `input.rebind`, `ctx.settings.*` flags). |
| Locale | `assets.locales` name -> JSON texts; `ctx.locale` (persisted) picks the table, `config.locale` is the default and fallback. `ctx.t(key, params)` fills `{name}`, picks `{ zero?, one, other }` by `count`, shows `[key]` when missing (one dev warning per key). |
| data-t | RmlUi attribute: the element's text is `ctx.t(key)` (`ui/translate`), applied when documents load and when the locale changes. |
| Reduced motion | `ctx.settings.reducedMotion`: camera shake intensity and emitter rate/burst/max and `emit(n)` scaled by `core::kReducedMotion` (1/4). |
| File layer (vfs) | `platform/vfs`: the engine's only door to files, on SDL_IOStream / SDL filesystem calls (folders, Android APK assets, later archives). Whole-file reads closed at once (nothing stays open: hot reload can replace the pack), decoders read from memory, `write_atomic` (temp + `.bak` + rename), `files_under` for the pack watch. Kept true by `tools/check_file_access.py`. |
| Pack root | The directory (later: APK assets or an archive) a game's asset names resolve under: `vfs::in_pack(root, "assets/a.png")`. Games never name absolute paths. |
| App pause | The app is paused while backgrounded or terminating, or (with `config.pauseOnFocusLoss`, default true, interactive runs only) minimized or unfocused: no steps, audio device paused, `ctx.app.paused`; `ctx.onPause` / `ctx.onResume` / `ctx.onLowMemory` are scene-scoped hooks. `core::AppLifecycle` is the pure state machine; resume restarts the fixed-step clock (no catch-up). Not the agent's `pause` (MCP) nor a script-error pause. |
| Section (perf) | A slice of a frame's time: script, timers (callbacks + tweens), physics, particles, animation, ui, render, audio (`core::Section`). Natives and the world time theirs; script = the step call minus them. Collected only with `core::kProfile` (dev tools, MCP or debug tools builds). |
| Perf history | `core::PerfHistory`: the newest 600 frames of `FrameTimes`; p50/p95/max per section (`core::to_json`). Shown in the dev tools Profiler window, as MCP `game_state.perf`, and written by `--perf PATH` for `tools/bench.py`. |
| ctx.positions(tag) | Batch read/write of every tagged entity's position: `{ count, ids, x, y, write() }` over one ArrayBuffer (two native calls in total instead of 2-3 per entity per access). `write()` skips entities destroyed since the read. |
| Native caps | `core/limits.hpp`: limits on native memory a script can request (array items, entities per world, displayed text, synth notes, game instances); the JS heap limit does not cover them. Live particles per world: `kMaxParticles`. |
| Template | A ready project `alpha init <dir> --template <name>` copies from `alpha-sdk/templates/<name>` (blank, platformer, topdown, puzzle, shmup). Each is a complete small game with tests and an `AGENTS.md`. All but `blank` mirror `examples/<name>` (`npm run templates`; the SDK tests fail on drift). npm drops `.gitignore` from packages, so templates store `gitignore` and `init` renames it. |
| Docs site | `docs/site/*.html`, generated by `alpha-sdk/scripts/make-docs.mjs` (`npm run docs`) from `docs/guide/*.md` and `types/alpha.d.ts`; opens from disk (no CDN, no scripts). `--check` (SDK tests) fails when stale. |
| API reference | `docs/site/reference.html`: every declaration of the `"alpha"` and `"alpha/test"` modules with its JSDoc and members, read by the TypeScript parser (`apiEntries`). |
| Version | One number for the engine (`CMakeLists.txt` project VERSION) and `@alpha-star/sdk` (`alpha --version`); semver, 0.x minor bumps may change the script API. |
| Alpha shim | `alpha-sdk/lib/alpha-shim.mjs`: the stand-in for the engine's "alpha" module the exporter uses to evaluate a game in Node (to read its assets). Must export everything `src/script/alpha.js` exports (checked by a test). |
| Android project | What `alpha export --target android-arm64` writes (default `build/android`): the SDK's `alpha-sdk/android/` Gradle template (SDL 3.2.10's `SDLActivity` Java glue, Gradle 8.12 wrapper, AGP 8.7.3), the pack in `app/src/main/assets`, the engine built from source by CMake externalNativeBuild (shipping flavor, arm64-v8a, `libmain.so` + `libSDL3.so`). Package id / icon / versions from `config.android`; orientation from `config.size`. Builds the APK only when the pinned toolchain (`TOOLCHAIN` in `lib/android.mjs`) is installed. |
| Touch inputs | `"Touch"` (any finger), `"TouchLeft"` / `"TouchRight"` (a finger on that half of the window): player 1's virtual buttons, `core::Touches` fed by `platform::apply_touch`. A finger is also SDL's emulated mouse (`"MouseLeft"`, `ctx.input.mouse()`). |
| Back input | `"Back"`: the Android back button (`SDL_SCANCODE_AC_BACK`; `prepare_mobile` traps it so it never closes the app). |
| Lifecycle watch | `platform::LifecycleWatch`: an SDL event watch for the OS lifecycle events (background, foreground, terminating, low memory), which SDL 3.2+ never queues (watchers only). On the pushing thread it records them under a lock, flags "leaving" (background / terminating) and flushes stderr; `AppEvents` stops stepping while flagged and `AppEvents::drain` (once per frame, after polling) feeds them to `AppLifecycle` and the hooks. Window focus / minimize / restore stay queued events. |
| PostFx | A scene's full-screen effect chain (`ctx.postfx`, `core::PostFx`): built-in effects in first-add order, render-only. |
| Compositor | `render::Compositor`: lighting and post effects on SDL_Renderer (render targets, add/modulate blends, vertex colors); built-ins use no shaders, custom shader effects go through `ShaderStates`. |
| Custom shader | An `assets.shaders` entry (`core::Shader`): a Vulkan GLSL fragment shader (`.frag`), its float uniforms in std140 block order (max `kMaxShaderUniforms`) and its compiled blobs; used as a postfx effect of kind `Shader`, named by its asset name. Runs on Vulkan only. |
| Shader blob | A compiled shader for one GPU backend format (`core::ShaderFormat`: SPIR-V only today; Metal planned), `<name>.spv` next to the .frag in a pack; `core::pick_format` is the one place that picks a format the device accepts. |
| glslang | Khronos glslang's standalone compiler (`cmake/Glslang.cmake`, built from source at a pinned tag), a dev/build-time tool next to the release engine: `platform::compile_shader` (ALPHA_DEBUG_TOOLS) and `alpha export` (lib/shaders.mjs) run it (GLSL -> SPIR-V); never linked into or shipped with the engine. `ALPHA_GLSLANG` overrides its path. |
| ShaderStates | `render::ShaderStates`: SDL GPU shader + `SDL_GPURenderState` per custom shader, made on first use, freed when the game drops the shader; skips (one warning) when the renderer is not SDL's GPU renderer. |
| Lightmap | Offscreen texture cleared to `config.lighting.ambient` with every entity `light` added, multiplied into the world. |
| game.jsbc | A standalone pack's game: QuickJS bytecode of the bundled main.js (no source, no debug info) behind a 64-byte header (`core/bytecode.hpp`: magic `ALPHAJBC`, format, body length, FNV-1a 64 checksum, build stamp). Written by `alpha_star --compile` (release engine); a pack directory runs it instead of main.js (`platform::pack_entry`). Not encryption. |
| Platform package | `@alpha-star/engine-<platform>-<arch>` (win32-x64, linux-x64): the release engine + `shipping/` engine, LICENSE and THIRD_PARTY_NOTICES.txt, with `os`/`cpu` set; an exact-version optionalDependency of `@alpha-star/sdk` (esbuild pattern). `lib/engine.mjs` looks there first, then `alpha-sdk/engine/<target>/`. Built by `tools/pack_release.py` into `dist/release/`. |
| Signing hook | `alpha export --standalone --sign`: runs the user's `$ALPHA_SIGN_CMD` with `{file}` = the pack's engine copy; the SDK stores no keys. `check_shipping.py --pack --signed` accepts an engine equal to the staged one minus its Authenticode signature. Android: keystore from `ALPHA_ANDROID_KEYSTORE*` env in Gradle. |
| Pack trust | Threat model: the pack folder is trusted like a native game's files. The game.jsbc header catches accidents (truncation, other versions), not crafted files; bytecode signing would need a key shipped in the engine, so it is not done. |
| Build stamp | `core::BuildStamp` (engine version, QuickJS version, build id = hash of the QuickJS sources + pointer width, from `src/CMakeLists.txt`): an engine runs only game.jsbc carrying exactly its own stamp, and says both stamps when they differ. |
| Platform | `ctx.platform` `{ os, mobile }`: `core::Os` from `SDL_GetPlatform()` (`core::os_from_sdl`), read by `platform::running_os()`; `--platform <os>` (debug tools) previews another one, `simulate({ platform })` picks one per test. For hints and layout only, never game rules. |
| Shake toggle | `devtools::ShakeToggle`: React Native's dev menu gesture. 4 accelerometer jolts above 13 m/s^2 (~1.33 g) within 1 s open/close the dev tools on phones (debug APKs); the Menu key (`adb shell input keyevent 82`, emulator Ctrl+M) does the same. |
| Android variant | `alpha export --variant`: `debug` (assembleDebug, release engine flavor with dev tools), `release` (assembleRelease APK, shipping), `bundle` (bundleRelease AAB for Google Play, shipping). |
| Dev tools layout | `devtools::tools_scale` (larger of the display content scale and the screen's shorter side / 1080, within 1..4: ImGui sizes and `FontScaleDpi`, crisp text) and `devtools::layout_panels` (pure: overlay + time on top, console along the bottom, entities + profiler between, side by side in landscape / stacked in portrait, inside `SDL_GetWindowSafeArea`). Windows go back to their places each time the tools open. |
